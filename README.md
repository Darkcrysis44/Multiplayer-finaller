# Love Sword Arena — Multiplayer Arrow Sync + Aim Fix

This build keeps the full previous project and fixes:

- Multiplayer sword/bow arm and hand now follow the latest attack direction.
- Bow projectiles are server-simulated instead of dealing damage at attack time.
- An arrow deals damage only when its server-side projectile reaches the first enemy it collides with.
- Projectile spawn, travel and confirmed hit are synchronized to all clients.
- Existing revive, restart, upgrades, solo and co-op systems are preserved.
